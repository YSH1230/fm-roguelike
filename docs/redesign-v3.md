# FM-Roguelike v3 설계 (논의 확정본, 미구현)

감독→전술 철학/라커룸 토크 개편(v2 후속, **라커룸 토크는 2026-10-15 삭제**) 위에 얹는 **정보 은폐 + 스카우트 영입 + 부상** 개편.
상태: 설계 합의 완료, 구현 전. 튜토리얼/컷신/밸런스 표는 초안(§8~10)이며 확인 대기.

## 1. 선수 표시 (OVR 삭제)
- 화면에서 숫자 OVR 제거. 선수 카드 = **별 0.5단위(1~5) + 태그 + 성향 문구 + 포지션**.
- 별은 **현재 리그 안 상대 평가**(승격하면 같은 선수가 한 칸쯤 낮아 보임).
- 내부 OVR은 숨은 값으로 유지(엔진 유지, 표시 계층만 변환).
- 별 = "세상의 평가(관측값)". 실제 기여는 숨은 값 → 별 높은데 못하고, 낮은데 잘할 수 있음.
- 괴리 원인: ① 관측 오차 ② 시즌 폼(시즌 시작 시 선수별 보정 ±3, 기복형 ±6, 시즌 평점으로 드러남) ③ 태그·팀 궁합.
- 시즌 평점은 실력의 증거(기존 유지). 가격은 별 구간 단위 + 노이즈(정답지 방지).
- 자동 선발은 **별 기준**(숨은 실력이 벤치에 앉을 수 있음, 직접 교체 가능). 선발 추천 칩은 전반기 이후 평점 기반. 팀 전력 계산은 실제 출전 선발의 숨은 값.

## 2. 별 갱신 (확정 없음)
- 영입 전: 범위(프로 ±1.5 / 베테랑 ±1.0 / 마스터 ±0.5), 1~5로 클램프.
- 영입 후 첫 **전반기 결산**에 범위가 한 점으로 좁아짐(평점 반영). 이후 **시즌 결산**마다 성장·쇠퇴로 숨은 실력이 변하고 별도 ±0~1 이동. 한 점이어도 ±0.5 오차는 남김(확정 없음). 큰 이동은 짧은 알림.

## 3. 영입 = 스카우트 지시 (매주 3명 상점 폐지)
- 1주차: 튜토리얼 + 고정 선수단, 돈 안 씀. 지시 연습까지만, 그 지시가 2주차에 실제 3명으로 도착.
- 지시 칸: 포지션 / 태그 / 나이대(유망·즉전력·베테랑). 칸 수 = 스카우터 레벨 1/2/3. 많이 채울수록 후보 좁아짐(3명 모두 조건 충족).
- 비용: 시간만(다음 주 도착). 지시 안 하면 랜덤 3명. 지시를 바꾸면 다음 주 새 3명(이전 3명 소멸).
- 3명은 **서로 다른 숨은 유형**. 유저는 유형을 모름(정체 공개도 없음). 협상 슬라이더/판매 오퍼/거래 벌칙 유지, 호가는 별 구간 단위+노이즈.
- 보이는 힌트: 별 범위, 나이, 태그, 성향 문구(실제 속성의 힌트이나 가끔 틀림, 스카우터 레벨이 높을수록 정확), 부상 이력 칩.

## 4. 숨은 속성 축 (유형은 조합, 선수당 3~4축만 활성)
| 축 | 값 | 효과 |
|---|---|---|
| 관측 오차 | 보석(+)/거품(−)/정확 | 별과 실제 차이 |
| 폼 변동 | 큼/작음 | 시즌 폼 폭 |
| 성장 곡선 | 대기만성/조기/보통 | 기존 성장 단계 |
| 시즌 내 리듬 | 슬로 스타터/전반 강/균일 | 전·후반기 폼 차이 |
| 팀 기여 | 팀플레이어/개인주의 | 조직력 기여 vs 개인 |
| 리그 적응 | 승격 체질/하위리그 왕 | 승격 시 변화 |
| 신입 적응 | 빠름/느림 | 영입 첫 시즌 폼 |
| 내구성 | 철인/보통/유리몸 | §6 부상 |
- 성향 문구는 축별 후보를 여러 개 두고 섞음. 시즌 평점 화면은 "전반기 부진·후반기 상승" 같은 **현상만** 요약(원인 비공개).

## 5. 팀 전력 정보 (시즌 중 완전 비밀)
- 시즌 중 예상 순위 밴드/라인 게이지/전력 숫자 없음. 상시 노출은 **수량 경고**("MF 얇음", 선수 수 기준)뿐.
- **전반기·후반기 시작 직전 시즌 전망 연출**: 기자 3명 예상 순위 + **이적시장 성적표**(영입별 한 줄 평 + 전체 등급, 대중 평판 기준이라 틀릴 수 있음).
  - 분석가: 실제 ±2 (약 15% 시즌은 ±5 이상 빗나감). 낙관파 +3위, 비관파 −3위 편향. (결산 대조는 하지 않기로 함.)

## 6. 부상 (내구성)
| 단계 | 처리 | 반기당 확률(보통, 시뮬 조정) |
|---|---|---|
| 잔부상 | 선발일 때 승점 −0.2 | 14% |
| 중간 부상(반기 절반) | 선발일 때 승점 −0.6 | 6% |
| 반기 아웃 | 선발 제외, 정원 칸 차지, 판매 가능(가격 하락) | 3% |
| 시즌 아웃 | 위와 동일, 시즌 남은 기간 | 1% |
- 내구성 철인 ×0.4 / 유리몸 ×2.0, 33세 이상 ×1.3. 목표 손실 시즌당 약 −2점(시뮬로 조정).
- 잔부상·중간: 반기 시뮬 중 발생, 결산에 요약(대응 불가). 반기 아웃·시즌 아웃: **여름·겨울 시장 모두에서** 시장 중간(3~4주차)에 알림 → 이후 주차에 대체 영입/판매로 대응.
- 유저 대응은 사후(겨울/여름 시장) + ~~라커룸 토크 소폭 효과~~(삭제됨). 새 스태프 없음.
- 표시: 부상 중일 때만 카드 배지, 결산에 한 줄. 이력 칩("잔부상 많음", "지난 시즌 중간 부상", "지난 시즌 시즌 아웃", "부상 이력 없음")은 내구성에서 샘플링한 가상 이력, 영입 후엔 실제로 갱신. 스카우터 레벨별 칩 수 1/2/3. 정확한 일수 비공개.

## 7. 구현 순서(안)
별 변환 계층 → 숨은 속성/폼/관측 오차 → 스카우트 지시·도착·유형 → 결산 갱신 → 부상 → 시즌 전망 연출 → 시뮬 재튜닝 → 튜토리얼/컷신.

## 8. 튜토리얼 새 흐름 (초안)
1주차: ① 목표선(임시 감독 서사) ② 선수 카드 읽기(별·태그·문구) ③ 선발/포메이션/팀 스타일 ④ 스카우터 지시 입력 ⑤ 다음 주로.
2주차: ⑥ 3명 도착(별 범위 읽기) ⑦ 1명 영입(협상) ⑧ 선수단 정원 ⑨ 감독·스태프 탭 ⑩ 다음 주로 … 전반기 시작 직전 ⑪ 시즌 전망 연출(기자 3명) ⑫ 전반기 결산(별이 한 점으로, 평점 읽기).

## 9. 컷신 (초안)
고정 인물: **이사장**(선임·기자회견), **주장**(~~라커룸 토크 반응~~ 폐기, 임명·C 표기·엔딩 대사는 유지), **스카우터**(영입 조언). 이야기는 "세 사람이 감독을 어떻게 보는가"의 변화(의심→신뢰). 장면: 정식 선임 기자회견(플래시), 라커룸 토크 반응 공개(주장 한마디), 시즌 전망(기자 3명), 큰 부상 알림(코치). 컷신형(한 화면 한 장면, 스킵 가능), 매 시즌 짧게.

## 10. 밸런스 표 (초안, 시뮬로 조정)
- 별 눈금: 현재 리그 선수 풀의 분위수로 1~5(0.5 단위), 리그마다 재계산.
- 시즌 폼 σ 2(기복 6), 관측 오차 σ 별 ±0.5 기준, 부상 §6.
