## 2. 별 눈금 (S4)

```
별(원점수) = 3 + (관측 OVR − 리그 기준) / 6
별(표시)   = round(원점수 × 2) / 2, 1~5로 자름
관측 OVR   = baseOVR + obsErr
```

| 리그 | 기준(영입 풀 중앙값) |
|---|---|
| 5부 | 59 |
| 4부 | 64 |
| 3부 | 72 |
| 2부 | 77 |
| 1부 | 83 |
- 상수표는 `SHOP_TIER_WEIGHTS_BY_TIER`(영입 풀 가중치)를 바꾸면 시뮬로 다시 계산한다.
- 현행(`leagueMid` = 리그 평균 전력 + 6, 눈금 4)은 폐기.
- 승격 시 별 하락: 기준 +5/+8/+5/+6 → 0.8~1.3칸(현행 1.5~2.75칸).
- 영입 카드 분포(측정): 모든 리그에서 평균 ★3, ★5 9~18%. 5부 시작 선수단은 평균 ★2.2(영입 풀이 더 좋다는 뜻).
- 시작 선수단 문구: "리그 평균 선수=★3" → "시장 평균=★3".

## 3. 폼·관측 모델

### 3.1 폼(시즌 내내 유지되는 숨은 보정)
```
FORM_SIGMA = { steady: 1.5, normal: 2.5, streaky: 4 }      // 기복 5→4
FORM_RHO   = { steady: 0.5, normal: 0.25, streaky: 0.05 }
ρ(p)       = clamp(FORM_RHO[vol] + 0.15 × clamp((baseOVR − 리그기준)/12, −1, 1), 0, 0.85)
올해 폼    = ρ × 작년 폼 + √(1−ρ²) × FORM_SIGMA[vol] × 난수(N(0,1))
```
- 시즌 시작에 `nextForm(p, mid)`로 갱신(현행 `rollForm` 대체).
- 높은 OVR + 꾸준 = 폼이 오래(ρ ↑), 낮은 OVR + 기복 = 폼이 빨리 리셋(ρ ↓).
- "올리는 힘"은 OVR이 이미 더해지므로 폼 평균은 올리지 않는다.

### 3.2 영입 시 초기값 (C-2)
```
작년 폼(prev) = FORM_SIGMA[vol] × N(0,1)
obsErr0       = 3.0 × N(0,1) + 0.5 × prev          // 평가 잡음 σ 3.0 (현행 4.5)
form0         = ρ × prev + √(1−ρ²) × FORM_SIGMA × N(0,1)
obsP0         = 3.0² + (0.5 × FORM_SIGMA)²          // 별 오차 분산(칼만 P)
```
- 생성 코드: `rollHiddenTraits`(engine/stars.mjs). 별 오차 총 sd ≈ 3.1~3.9 OVR(≈ 0.5~0.65★).

### 3.3 별 갱신 (칼만 + 이득 하한)
반기 결산마다 2번(전반기: perf = form + hiddenShift(전반기), 시즌 결산: perf = form).
```
K      = max( P / (P + R[vol]), KMIN[vol] )
obsErr = obsErr + K × (perf − obsErr)
P      = (1−K)² × P + K² × FORM_SIGMA[vol]²
R      = { steady: 38, normal: 66, streaky: 25 }
KMIN   = { steady: 0.25, normal: 0.15, streaky: 0.15 }
```
- 현행은 `obsErr ← 0.5×obsErr + 0.5×perf` 고정이라 기복형이 영원히 안 수렴(sd 3.9 고정).
- 시즌당 활약 반영 비율(수렴 후): 꾸준 44% / 보통 28% / 기복 28%(현행 75%).
- 저장: 선수에 `obsP`(별 오차 분산)와 `prevForm`(작년 폼, 리포트 ② 근거) 필드 추가. 없는 이전 세이브는 obsP0·prevForm 0으로 간주(이어하기 가능). `nextForm`이 폼을 새로 굴릴 때 이전 form을 prevForm에 저장한다.
- 수렴 시즌·표시 폭은 아래 4.2의 보정표를 쓰고 obsP는 이득 계산에만 쓴다(분석식이 증거 상관을 무시해 폭을 낮게 계산하므로).

## 4. 성장폭(예상 별 범위)과 스태프 리포트

### 4.1 리포트 구조 (사용자 확정 2026-10-14)
항상 보이는 항목(등급 무관)과 등급별 차등 항목으로 나눈다.
| 구분 | 항목 | 표시 | 값의 근거 | 정확도(내부) |
|---|---|---|---|---|
| 항상 | ① 성장폭 | "성장폭 ★2.5~3.5" + 화살표(↗/→/↘) + 성장 등급(S~C, 성장성 칩 흡수) | 4.2 | 등급별(중심 오차) |
| 항상 | ② 작년 흐름 | 호조 / 보통 / 부진 | 작년 폼(`prevForm`): ≥ +0.7σ 호조, ≤ −0.7σ 부진, 그 사이 보통(σ = 그 선수 유형의 FORM_SIGMA). 분포 약 24/52/24% | **100%(사실)** |
| 항상 | ③ 부상 이력 | 칩 최대 2개(시즌 아웃 / 반기 아웃 / 잔부상 많음). 접힌 칩은 부위 없이 "지난 시즌 시즌 아웃", 펼치면 부위("십자인대 파열"). 없으면 "이력 없음" | 4.6 | **100%(사실)** |
| 차등 1 | ④ 자리 판단 | 즉시 전력 / 로테이션 / 미달 | 숨은 실력(baseOVR + form) − 같은 자리 선발 중 최저: ≥ +2 즉시, −3~+2 로테이션, ≤ −3 미달. 같은 자리가 공석이면 "즉시 전력" | 등급별 |
| 차등 2 | ⑤ 이름값 | 고평가 / 저평가 / 적정 | obsErr(별−base): ≥ +3 고평가, ≤ −3 저평가, 그 사이 적정 | 등급별 |
| 차등 3 | ⑥ 내구성 | 철인 / 보통 / 유리몸 | 숨은 durability 축(iron/normal/fragile = 20/60/20%) | 등급별 |
| 차등 4 | ⑦ 성향 | 숨은 특성 문구 한 줄(최대 2개) | 활성 특성 중 우선순위 순으로 2개: 기복·꾸준 → 시즌 리듬 → 팀 기여 → 리그 적응 → 새 팀 적응 → 성장 곡선 | 등급별 |
- 성향 문구에서 이름값(rep)·내구성 문구는 제외한다(⑤⑥으로 이관해 중복 제거). 부상 이력 칩 개수 상수 `INJURY_CHIP_COUNT`는 폐지(항상 2).

| 등급(스카우터·코치) | 차등 항목 | 합계 줄 수 | 내부 정확도 ACC |
|---|---|---|---|
| 아카데미 | ④ | 4(항상 3 + 1) | .55 |
| 프로 | ④⑤ | 5 | .68 |
| 베테랑 | ④⑤⑥ | 6 | .78 |
| 마스터 | ④⑤⑥⑦ | 7 | .80 |
- ACC는 **화면에 표시하지 않는다**(칩·안내 줄에서 "정확도 N%" 제거). 모든 추정의 상한 .80.
- 범주형(④⑤⑥) 오답 규칙: 같은 선수·같은 등급이면 항상 같은 답(`hash32(p.id|level|report|항목)` 기반 의사 난수). 맞으면 참값, 틀리면 인접 범주(④⑤: 양끝은 가운데, 가운데는 임의의 한쪽 끝; ⑥: 나머지 둘 중 하나).
- ⑦ 성향 오답 규칙: 기존 `traitHints`와 같음(맞으면 참 문구, 틀리면 전체 문구 중 임의 문구).
- 작년 흐름 상시 노출의 영향(측정): 후보 3명 중 별이 가장 높은 카드를 고를 때 기대 실제 OVR 64.51 → 64.56(+0.04). 기복형의 별 오차 sd 3.58 → 2.98. 누출·도박성 손실은 사실상 없음(시장 가격은 이미 관측값으로 매겨짐).

### 4.2 성장폭 계산
```
W (별)   = √( P_표 + σ_age² ) / 6,   σ_age = 1.2 OVR
성장폭   = 중심 ± 1.28 × W            // 80% 구간
중심     = 현재 별 + 나이 기대 변화/6 + 등급 오차
등급 오차= 고정 hash 가우스 × W × { 아카데미 1.37, 프로 0.81, 베테랑 0.30, 마스터 0 }
```
- 표시 폭은 0.5★ 단위로 반올림, 최소 0.5★.
- P_표 = 3.4의 보정표(유형·보유 시즌별 sd²). 영입 직후 첫 표시: 꾸준 1.40★, 보통 1.47★, 기복 1.62★ 폭.
- 코치(내 선수단)는 같은 형식. 보유 보정: 모든 항목 정확도 +0.04/시즌 보유(상한 .80). 성장성 σ 하한 1.55(80% 지점)로 올림(현행 0.8).

|---|---|

### 4.4 표시 규칙(깔끔하게)
- 시장 카드: 별 한 줄 + 리포트 칩 최대 3개(성장폭·작년 흐름·자리 판단), 눌러서 펼치면 나머지 전체.
- 내 선수단 행: 접힌 상태엔 별과 ▲/▼만, 펼친 영역에 코치 리포트 전체.
- 별 옆에 범위·등급색·≈·검증 칩 등 추가 요소 없음.
- 스카우터 칩("평가 범위 ±N★")은 "리포트 N항목"으로 교체(정확도 숫자 표시 없음).

### 4.5 코치 역할
| 항목 | 현재 | 최종 |
|---|---|---|
| 육성(성장 +1 확률/정체 감소) | 0/.3/.6/1.0 | 유지 |

### 4.6 부상 이력과 부상 부위 (사용자 확정 2026-10-14)
**규칙**
- 부상 이력(칩) 종류는 **시즌 아웃 / 반기 아웃 / 잔부상 많음(잔부상 2회 이상)** 세 가지다. **중간 부상은 이력에서 제외**(승점 감점은 그대로). 없으면 "이력 없음".
- 접힌 칩(시장 카드·선수단 행 접힘): 부위 없이 `{지난 시즌|이번 시즌} {시즌 아웃|반기 아웃}`(예: "지난 시즌 시즌 아웃"), 또는 "잔부상 많음". 심한 순서(시즌 아웃 → 반기 아웃 → 잔부상 많음)로 최대 2칩.
- 펼친 줄(카드를 눌러 펼쳤을 때): 같은 순서로 부위를 보여 준다(예: "십자인대 파열", "햄스트링 파열"). 잔부상 많음은 부위가 없다.
- 시장 중간 부상 알림(`showInjuryPopup`)과 선수단 행의 ✚ 태그(부상 중인 선수)는 부위를 바로 보여 준다: 팝업 제목 "OOO(포지션) 십자인대 파열 · 시즌 아웃", 여럿이면 한 줄씩 "이름(포지션) · 부위 · 구분". 선수단 행 태그는 "십자인대 파열(시즌 아웃)".
- 부위는 **표시용(승점·기간에 영향 없음)**: 아웃 기간은 기존 규칙 그대로(반기 아웃 1반기, 시즌 아웃 여름 2반기 / 겨울 1반기).
- 반기 시뮬 중 잔부상·중간 부상은 "반기 결산 부상 목록"(`injuriesHtml`)에 구분 이름만 유지(부위 없음). 이 중 **잔부상만** 이력에 기록한다(중간 부상은 기록하지 않음).

## 12. 시뮬 결과 (sim-v3 normal 봇, 구성요소를 하나씩 쌓은 분리 측정)
구성: A 나이 개편 → +B 폼 지속·C-2·σ기복 4 → +C 칼만(K 하한 유형별) → +D 눈금 S4·단일 별(봇이 보는 별에서 범위 제거) → +E 스카우터 수치(전체). 난수 시드 미고정, N=500(A 단계만 N=300).
| 구성 | 평균 완주 시즌(SE) | 1부 도달 | 1부 우승 | 별↔올해 폼 괴리(visErr) |
|---|---|---|---|---|
| 현행 | 7.21 (0.19) | 20% | 23명(4.6%) | 2.06 |
| A 나이 | 7.65 (0.27) | 25% | 12명(4.0%) | 2.04 |
| A+B | 7.40 (0.19) | 24% | 19명(3.8%) | 1.67 |
| A+B+C | 7.20 (0.18) | 19% | 15명(3.0%) | 2.29 |
| A+B+C+D | 7.63 (0.19) | 27% | 23명(4.6%) | 2.34 |
| **전체(확정 규칙)** | **7.78 (0.20)** | **28%** | **20명(4.0%)** | 2.34 |
- 평균 완주 시즌은 전체 확정 규칙이 현행보다 +0.57(차이의 SE ≈ 0.28, 약 2σ)로 약간 늘어남. 1부 도달 20% → 28%.
- "1부 우승 5% → 3%"는 **칼만 단계(C)에서 3.0%로 낮아졌다가 D(눈금·단일 별)에서 4.6%로 회복**. 우승률의 표준오차가 약 0.9%p라 구성 간 차이는 잡음 수준. 최종 규칙은 4.0%(현행 4.6%와 구분 안 됨).
- D가 도움이 되는 이유(추정): 눈금 4·mid 기준에서는 5부 영입 카드가 ★5로 포화(봇도 구분 불가)했는데 S4(눈금 6, 풀 중앙값 기준)는 포화가 사라져 봇의 선택이 나아짐.
- 별↔폼 괴리는 칼만 도입 후 2.06 → 2.29~2.34로 커짐(별이 올해 활약을 덜 따라가므로 의도된 결과). 별−base 오차는 3.3절 표대로 수렴.
- 한계: 봇은 스태프 리포트 정보를 쓰지 않는다(리포트의 난이도 영향은 UI 구현 후 사람 플레이로 확인). 숙련(skilled) 봇은 이번에 돌리지 않음.

## 13. 구현 체크리스트 (프로그래밍 세션용)
각 단계는 독립적으로 커밋 가능하게 끊었고, 단계마다 **테스트 기준**을 통과해야 다음으로 간다. 시뮬은 `tools/sim-v3.mjs`에 같은 변경을 넣은 뒤 `BOT=normal node tools/sim-v3.mjs 500 --out 파일.json`으로 돌린다(이전 측정은 `process.env` 플래그를 쓴 저장소 밖 임시 복사본).

### 단계 0. 준비
- 현행 기준선: `BOT=normal node tools/sim-v3.mjs 500` → 평균 완주 시즌 약 7.2(SE 0.2), 1부 도달 약 20%, 1부 우승 약 4.6%를 기록해 둔다(난수 시드는 고정되지 않으므로 ±1 SE 안이면 정상).
- 점검 스크립트는 `tools/check-*.mjs`(예: 기존 `tools/check-personality.mjs`)처럼 노드 단독 실행·`console.assert` 방식으로 만든다.

### 단계 1. 엔진: 눈금·폼·별 갱신
수정 파일: `engine/stars.mjs`, `engine/constants.mjs`, `ui/app.mjs`(leagueMid 한 곳), `tools/sim-v3.mjs`·`tools/sim-human.mjs`(midOf).
1. 상수 추가(`engine/stars.mjs`)
   - `OVR_PER_STAR = 6`
   - `STAR_ANCHOR_BY_TIER = { tier5: 59, tier4: 64, tier3: 72, tier2: 77, tier1: 83 }`
   - `FORM_SIGMA = { steady: 1.5, normal: 2.5, streaky: 4 }`, `FORM_RHO = { steady: 0.5, normal: 0.25, streaky: 0.05 }`
   - `OBS_R = { steady: 38, normal: 66, streaky: 25 }`, `OBS_KMIN = { steady: 0.25, normal: 0.15, streaky: 0.15 }`
2. `starsOf(p, anchor)`: `3 + (observedOVR(p) − anchor) / 6`, 0.5 단위 반올림, 1~5로 자름. `ui/app.mjs`의 `leagueMid()`(225행 근처)는 `STAR_ANCHOR_BY_TIER[currentState.leagueTierId]`를 돌려주게 교체.
3. `nextForm(p, anchor)` 신설(`rollForm` 대체): `rho = clamp(FORM_RHO[vol] + 0.15 × clamp((baseOVR − anchor) / 12, −1, 1), 0, 0.85)`, `form = rho × 이전 form + √(1 − rho²) × FORM_SIGMA[vol] × N(0,1)`(소수 1자리). 갱신 전 form을 `prevForm`에 저장.
4. `rollHiddenTraits`: `prev = FORM_SIGMA[vol] × N(0,1)`, `obsErr = 3.0 × N(0,1) + 0.5 × prev`, `form = rho0 × prev + √(1 − rho0²) × FORM_SIGMA × N(0,1)`(rho0 = OVR 연동 없는 `FORM_RHO[vol]`), `prevForm = prev`, `obsP = 3.0² + (0.5 × FORM_SIGMA[vol])²`.
5. `obsUpdate(p, perf)` 신설: `P = p.obsP ?? obsP0`, `K = max(P / (P + OBS_R[vol]), OBS_KMIN[vol])`, `obsErr += K × (perf − obsErr)`, `P = (1 − K)² × P + K² × FORM_SIGMA[vol]²`. 반기 결산 2번 호출: 전반기 `perf = form + hiddenShift`, 시즌 결산 `perf = form`(현행 `updateObservations`와 `startNewSeason`의 `0.5 × + 0.5 ×` 두 곳을 교체).
6. 삭제: `tierFromStars`, `starRange`, `rangeText`, `STAR_RANGE_HALF`, `OBS_ERR_SIGMA`.

테스트 기준
- `starsOf`: 5부 anchor 59에서 OVR 59 → ★3, 65 → ★4, 71 이상 → ★5, 47 이하 → ★1.
- `nextForm`: 유형별 폼 표준편차가 FORM_SIGMA의 ±10% 이내(각 2만 샘플).
- `obsUpdate` 수렴(영입 직후 obsErr 포함 1만 선수, 시즌 시작 sd, OVR, ±10%): 꾸준 ≈ 3.05 / 1.92 / 1.40 / 1.20, 보통 ≈ 3.23 / 2.52 / 2.03 / 1.72, 기복 ≈ 3.61 / 2.77 / 2.37 / 2.12(0~3시즌째).
- 영입 카드 별 분포(5부 3000장): ★5 비율 9~18%, 평균 ★2.9~3.2.
- sim-v3 N=500 normal: 평균 완주 시즌 6.9~8.4, 1부 도달 15~32%.
