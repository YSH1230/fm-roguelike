# FM-Lite 밸런스 측정과 1차 조정 (2026-10-16)

측정 도구: `node next/tools/sim.mjs [판 수] [최대 시즌] [basic|smart]` (환경변수 `RESERVE`=코치 재계약 예비 코인, 기본 60). 자동 감독이 오프시즌 재계약·FA·드래프트·신인 배치를 알아서 하고, `smart`는 남는 코인으로 시설을 올린다. 한 판 10시즌이 약 0.15초라 수백 판을 바로 돌릴 수 있다.

## 발견한 문제와 조정
| 문제 | 근거 | 조정 |
|---|---|---|
| **선수 성장이 거의 없음** | 3년 동안 스타 평균 능력이 +1 안팎, 어린 선수도 시즌당 +1~2 | 레벨업 필요 XP를 `50 + 10 x 레벨`에서 `15 + 3 x 레벨`로, 레벨업 때 능력 상승폭을 +1~2에서 +1~3으로(`XP_NEED_BASE` `XP_NEED_STEP` `LEVEL_GAIN`) |
| **시작이 너무 약함** | 1년차 평균 14위, 경질 15% | 시작 코치를 2별에서 2.5별로(`game.mjs`) |
| **2부 벽** | 2부에서 승격률 시즌당 11% | 2부 AI 코치 2~4별을 2~3.5별, 수준 50~66을 48~63, 기준 58을 56으로 / 1부 코치 3~5별을 3~4.5별, 수준 60~78을 58~74, 기준 69를 66으로 |
| **3부가 막힘** | 3부 승격률 낮음 | 3부 AI 코치 1.5~3.5를 1.5~3별, 수준 38~54를 36~52, 기준 46을 44로 |
| **4년차 절벽(자동 감독의 약점이면서 설계 경고)** | 시작 코치 2명과 스타 6명의 계약이 모두 3년이라 같은 해에 동시에 만료. 코인을 다 써 버리면 코치가 1별 신임 코치로 바뀌어 전력이 급락 | 도구의 자동 감독이 재계약 예비비를 남기도록 고침. 설계상 계약 만료 시기를 흩뜨리는 방법(시작 선수 계약 연수를 1~3년으로 다르게)은 아래 미결 항목 |

## 조정 후 측정 (smart, 80판 x 12시즌)
| 항목 | 값 |
|---|---|
| 1년차 3부 승격 | 36% |
| 2부 도달까지 평균 | 3.3시즌 |
| 12시즌 안에 1부 도달 | 51/80판 |
| 3부 시즌당 경질 | 1/185 (거의 없음) |
| 2부 시즌당 경질 / 승격 | 7% / 16% |

## 아직 측정하지 못한 것과 미결
- **한 시즌 소요 시간**(목표 6~8분)은 사람이 직접 해 봐야 안다. 화면 클릭 수는 시즌당 구간 3번 + 이벤트 몇 번 + 오프시즌 4단계.
- **자동 감독은 코치를 새로 고용하지 않고 트레이드·휴식·훈련 강도도 쓰지 않는다.** 사람이 하면 더 빨리 오른다. 사람 플레이 기록을 보고 난이도(특히 1부 경질 27%)를 다시 맞춘다.
- **계약 만료 동시성**: 시작 스타·코치가 모두 3년이라 첫 오프시즌(3시즌 뒤)에 한꺼번에 재계약을 해야 한다. 재미가 아니면 시작 계약 연수를 흩뜨린다(사용자 결정).
- **1부 경질 27%**가 의도에 맞는지(긴장감 vs 좌절), **3부 1년차 승격 36%**가 너무 쉬운지는 사용자 판단.
- 코인은 12시즌 후 450까지 쌓인다(시설을 다 올린 뒤 쓸 곳이 적음). 코치 고용·캡 확장 비용 곡선을 조정하거나 쓸 곳을 늘릴지 결정.
- 앞선 계획서(`docs/superpowers/plans/`)의 코드와 테스트 숫자 일부(XP 필요량 50/60/90, 시작 코치 2별, 리그 단계별 수준)는 이 조정으로 바뀌었다. 코드가 기준이고 계획서는 작성 당시 기록이다.
