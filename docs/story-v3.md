# 스토리·컷신 설계 (논의 확정본, 일부 미구현)

## 원칙
- 컷신은 숫자 효과를 바꾸지 않는다. 이미 있는 선택(철학, 라커룸 토크)을 담는 무대다.
- 사건에만 나온다(시즌마다 반복 X). 모든 컷신에 건너뛰기. 대사는 장면마다 여러 개 두고 최근에 나온 2개는 제외해서 반복을 막는다.
- 전제: "아무도 이름을 몰랐던" 5부 구단. 전임 감독이 시즌 도중 사라지자 이사장이 책임질 사람이 필요해서 플레이어를 임시 감독(허수아비)으로 앉혔다. 첫 시즌을 잔류하면 정식 감독.

## 인물
- **이사장**: 판(런)마다 이름이 바뀐다(생성). 건조하고 계산적, 숫자만 믿는다. 정식 선임·강등 위기·엔딩에 나온다.
- **주장**: 고정 인물이 아니라 **실제 선수**(가장 오래 뛴 선발, 동률이면 별 높은 선수). 이름·얼굴이 그대로 나온다.
- **스카우터 노라**: 고정 인물. 정식 선임 직후 한마디, 엔딩.
- **튜토리얼 진행자**: 별도 인물 1명(미정).
- 신뢰 단계(승격 횟수·우승 경험으로 계산, 저장 필드 불필요): 의심(승격 0회) / 조건부(1~2회) / 신뢰(3회 이상 또는 우승). 주장의 호칭이 감독 → 감독님 → 보스로 바뀐다.

## 장면
1. **정식 선임 기자회견**(첫 시즌 잔류): 기자 질문 3종 중 랜덤 → 이사장 답변 → 철학 질문 → 철학 선택 → 노라 한마디(3종).
2. **시즌 시작 전 라커룸**(정식 감독이 된 뒤): 선발 선수들이 앉아 있고 감독이 말하는 장면. 입장에는 대사가 없다(상황 캡션만). 감독이 라커룸 토크(3택1)를 고르면 감독의 한마디가 말풍선으로 나오고, **그 뒤에** 선수단 반응(기존 반응 서술)과 주장의 한 줄이 나온다. 주장 대사는 반응 톤(좋음/섞임/나쁨)별 4개씩, 호칭은 신뢰 단계별.
   - 시즌 마무리 토크도 같은 화면 재사용(캡션만 "시즌이 끝난 라커룸").
3. **강등 위기**(전반기 결산이 강등 페이스): 이사장 호출, 단계별 3대사. 연출만(선택지 없음).
4. **우승 시상**: 대사 없음. 우리 선발 11명(실제 초상화)이 트로피를 드는 화면 + 컨페티 + 캡션. 탭하면 시즌 결산으로.
5. **엔딩**(런 종료): 이사장·주장·노라 한 줄씩 + 기존 런 결과 화면.
6. **큰 부상**: 컷신이 아니라 일반 이벤트 팝업(구현됨). 닫기 버튼만.

## 대사 풀
(정식 선임·강등 위기·엔딩 대사는 대화 기록의 초안을 사용. 구현 시 이 문서에 확정본을 옮긴다.)

## 구현 현황 (2026-10-13)
- 정식 선임 기자회견, 시즌 시작·마무리 라커룸(주장=실제 선수), 강등 위기(이사장), 우승 시상(리그·챔피언스리그 별도), 엔딩, 큰 부상 팝업, 튜토리얼 진행자 모두 구현.
- 노라는 컷신·대사 없음(스카우터는 시스템 역할만). 이사장 이름은 판마다 새로 생성.
- 튜토리얼 진행자: 구단 사무국 신입 직원 **올리비아 하트**(고정 인물, 밝고 명랑한 성격, 도트 초상화 고정).
