## 1. 핵심 콘셉트

플레이어는 감독 겸 단장이 되어 자금 운용, 전술 수립, 덱빌딩을 총괄한다.
미니 경기 연출 없이, 완성된 덱의 수치를 합산해 38경기 시즌을 즉시 결산한다.
중심 재미는 **시너지 조합 퍼즐**이고, 경제는 그 조합을 어렵게 만드는
제약 장치이며, 커리어 스토리는 결과에 붙는 부가 요소다.

- 엔딩: 대륙 챔피언스 컵 우승. 이후 무한 모드 해금(어센션 방식으로 난이도 상승).
- 한 시즌 플레이 시간 목표: 8~10분. 한 런(승격 포함) 목표: 60~90분.
- 모든 선수·구단·리그는 가상(실존 라이선스 회피).
- 목표 난이도: 신규 유저 5부 잔류 성공률 60~70%, 5부 우승 20~30%,
  숙련자는 10런 이내 엔딩 도달.

## 2. 시즌 루프

1. **여름 이적시장 (Week 1~12, 아래 4개 구간)**: 자금 지급(구단 잔류 시 이월,
   상한은 다음 시즌 시작 자금의 30%), 선수/감독/스태프 영입.
2. **전반기 19경기 결산**: 순위표 연출(5~10초) + 핵심 사건 3~5줄 요약,
   결산 전 예상 승점 범위 공개.
3. **겨울 이적시장 (Week 9~12)**: 윈터 택스 +20%, 감독 중도 교체 가능
   (위약금 = 영입가 50%).
4. **후반기 19경기 결산**: 최종 승점 확정.
5. **거취 선택**:
   - 안전 승점 이상 + 잔류 선택 → 이 구단으로 계속 (같은 구단 승격 시
     선수단 유지, 4절 참고)
   - 목표 달성 + 이적 선택 → 성과에 비례한 오퍼(우승 3개, 목표 달성 2개)
     중 하나를 골라 새 구단으로 이동, **선수단 전부 초기화**
   - 안전 승점 미달 → 즉시 해임(Run 종료), 기대 목표 미달 3회 누적 시에도
     해임. 메타 재화 정산 후 재도전.

승점 변환은 리그 평균 OVR과 팀 평균 OVR의 차이를 기준으로 하며(6절),
구체 계수는 시뮬레이터로 튜닝한다(TBD, 8절 참고).

가격 변동 요소(영입비 할인/할증)가 여러 개 겹칠 경우: **전부 가산 합산 후
한 번만 적용**하며, 합산값은 **-60%~+80%로 클램프**한다. (기존에 검토했던
"윈터 택스×화술의 달인 곱연산" 방식은 이 규칙으로 대체됨.)

## 4. 구단 (Club)

구단은 선수단이 초기화될 때마다 새로 배정되는 콘텐츠 단위다.

- **같은 구단 잔류 후 승격**: 선수단 유지. 대신 승격 보상 + 승격 전용
  위기(9절)가 함께 적용된다.
- **다른 구단으로 이적**: 선수단 전부 초기화, 새 구단의 시작 선수단으로
  리셋. 감독 본인, 감독/스태프의 메타 progression은 이월. 스태프는
  이월하지 않고 새로 고용.
- **구단 성격 태그**: 강점 1개 + 약점 1개 쌍으로 구성. 새 규칙을 만들지
  않고 기존 시스템(시작 자금, 시작 선수단 편향, 태그 등장률)만 재사용한다.
- **슬라이스 구단 4종**:

| 구단 성격 | 강점 | 약점 |
|---|---|---|
| 유스 명문 | 시작 선수단에 성골 유스 다수 | 시작 자금 적음 |
| 오일머니 | 시작 자금 많음, 레전더리급 1명 보유 | 이적 오퍼 성과 기대치 큼 |
| 수비 전통 | 수비형 플레이스타일 편중, 적응도 시작 높음 | 공격 태그 카드 등장률 낮음 |
| 공격 축구 | 공격형 플레이스타일 편중 | 수비 포지션 OVR 낮음 |

(확장 후보: 베테랑 클럽, 국제 구단 — 슬라이스 이후)

- **명성 체계**: 구단 명성(고정, 시작 자금·리그 체급 결정) vs 감독 명성
  (런 동안 누적, 이적 오퍼 개수·품질과 메타 재화 환산 기준).

### 5.2 감독 (Manager)

3층 구조: **등급(배율) → 전술 성향(포메이션/전술 태그/대륙 태그) →
세부 성향(패시브 1개)**. 배율이 높을수록 세부 성향은 약하거나 없고,
배율이 낮을수록 강한 세부 성향을 갖는 반비례 밸런스. **예외: GOD 등급
감독(2명, 극희귀)은 배율 1.20과 강한 세부 성향을 동시에 가질 수 있다.**

- **배율**: 루키 1.00, 택티션 1.05, 레전더리 1.12, GOD 1.20.

  3-4-3 계열).
- **화술의 달인 계산**: 감독의 대륙 태그 1개 + 전술 태그 1개에 대해 각각
  영입비 -30%. 3절의 가산 합산·클램프 규칙에 포함됨.

### 5.3 스태프 (Staff)

선수·감독보다 명확히 약하게 설계. 가산/규칙 완화로만 작동하며 배율에
곱하지 않는다. 슬라이스는 2종만 구현.

|---|---|

## 6. 수치 엔진 원칙

1. 모든 태그 효과·특수 성향은 **선수 개인 OVR에 가산**한다(곱연산 시너지
   없음).
2. 그 다음 **팀 단위 배율만 곱한다**: 감독 배율 × 적응도 배율.
3. 합친 배율에 **상한(캡)**을 둔다(구체 값 TBD, 시뮬레이터로 결정).
4. 리그 체급표·승점 변환은 **베스트11 평균 OVR** 기준으로 비교한다.

```
평균 OVR = (Σ 베스트11 선수 개인 OVR(가산 후)) / 11
최종 전력 = 평균 OVR × 감독 배율 × 적응도 배율(캡 적용) ± 랜덤(±5%)
승점 = f(최종 전력 - 리그 평균 OVR)  ← 계수 TBD, 시뮬레이터로 튜닝
```

### 적응도(팀 조직력)

- 범위 0~100, 새 구단 시작값 60.
- 영입/방출/판매 1명당 -2(리빌딩 장인 -1 / 수석 코치 등급별 완화,
  중복 없이 더 강한 쪽만 적용, 용병 부대 방지 조항 시 -4).
- 스쿼드 변동 없는 주는 +1.
- 배율: 40 미만 ×0.95, 40~95 ×1.00~×1.04 선형, **96 이상 ×1.12**.

## 7. 경제

- **통화 단위**: G.
- **카드 가격(등급별 범위, 5부 기준, 리그 단계와 무관하게 고정)**:

| 등급 | OVR 범위 | 가격(G) |
|---|---|---|
| 로컬 | 50~62 | 10~40 |
| 빅리거 | 63~72 | 40~120 |
| 탑클래스 | 73~80 | 120~300 |
| 월드클래스 | 81~87 | 300~700 |
| 레전더리 | 88~94 | 700~1,600 |
| GOD | 95~99 | 개별 고정값(예: 4,000 / 4,500 — 2장 각각 수작업) |

같은 등급 내에서는 OVR에 비례해 선형으로 가격이 오른다.

- **시작 자금**: 5부 기준 1,000G, 리그 단계가 오를 때마다 ×1.5.
- **이월 상한**: 다음 시즌 시작 자금의 30%.
- **드래프트(상점형)**: 매주 3~5장(수석 스카우터 등급에 따라 증가) 전부
  구매 가능(자금이 제약), 리롤 유료(최고 등급 스카우터 -50%).
- **계약**: 신규 2년 고정. 재계약 1년 연장 원가 30%, 2년 연장 60%.
- **방출 3단계**: 즉시 방출(회수 0%) / 이적 명단 등재(1주 소모, 여름
  50~100%·겨울 70~110%, 당해 영입자는 겨울 매각 불가) / Week 12 데드라인
  (1주 소모 없이 40% 즉시 회수 또는 잔류).
- **윈터 택스**: 겨울 시장 영입 비용 +20% (3절의 가산 합산에 포함).
- **감독·스태프 시장**: 별도 탭에서 매주 후보 순환. 감독 위약금 = 영입가
  50%(겨울 시장에만 교체 가능). 스태프는 위약금 없이 즉시 교체(교체한
  주는 신규 스태프 효과 미발동, 소급 없음).

| 감독 등급 | 가격(G) |
|---|---|
| 루키 | 50~150 |
| 택티션 | 200~500 |
| 레전더리 | 800~1,500 |
| GOD(2명) | 개별 고정값 |

| 스태프 등급 | 가격(G) |
|---|---|
| 아카데미 | 20~50 |
| 프로 라이선스 | 60~150 |
| 베테랑 | 200~400 |
| 마스터 | 500~800 |

**슬라이스 1차 경제 범위**: 계약(2년/재계약), 방출 3단계, 윈터 택스만
구현. 사치세(레전더리/GOD 2장 이상 매주 예산 -15%), 용병 부대 방지
(고액 주급 -10% + 적응도 감가 2배)는 2차, 오일머니 메가 오퍼 같은
하이재킹형 이벤트는 이벤트 확장 때 추가.

## 8. 승격 보상 & 승격 전용 위기

**같은 구단으로 승격 시 선수단 유지**를 전제로 다음이 함께 적용된다.

### 승격 보상 (3개 전부 자동 지급, 수치는 시뮬레이터로 조정, 출발값)

- 시즌 초 적응도 +5(상한 100)
- 적응도 상승 속도 2배(해당 시즌 한정)
- 승격 축하금: 다음 시즌 자금 +10% (이월 상한과 별도 합산)

### 승격 전용 위기 (딜레마 선택형, 일반 이벤트 풀과 별개 시스템)

- 발동 시점: **승격 직후 시즌에만**. Week 1~3 초기 안전 구간에도 등장
  가능(일반 이벤트만 이 구간을 피함).
- 핵심 선수 재계약 비용 +30% (확정)
- 핵심 선수 이적 요구: 수락 시 40% 회수 방출, 거부 시 그 시즌 OVR -N
  (확정)
- 오일머니 메가 오퍼(핵심 선수 150~250% 매각 제안, 3절에서 개명)와
  몸값 인플레이션(이번 시장 상점 가격 +N%)은 슬라이스 이후 확장 후보.
- 강철 멘탈을 가진 핵심 선수는 **본인을 대상으로 하는** 위기를 무효화
  (감독의 위기 관리형은 팀 전체 1건 무효, 서로 다른 레이어).

## 9. 저장 / 계정

- **슬라이스**: 로그인 없음, 브라우저 로컬 저장만. 서버 없는 정적 구조
  유지. 저장 데이터 구조는 이후 서버 이전이 쉽도록 설계.
- **비상 복구**: 로그인한 사용자만 가능(우발적 종료 후 재접속 시 마지막
  상태 복구, 이어하기 1회 한정). 슬라이스에는 로그인이 없으므로 이후
  마일스톤 기능.
- **정식 저장(런 종료 후 재개)**: 메타 progression 해금 보상. 예:
  1부 승격 후 1시즌 우승 시 해금.

## 10. 메타 progression (슬라이스 범위 밖, 방향성만 기록)

- 다양성 해금 중심(새 감독, 새 태그, 새 스태프, 새 시작 리그), 파워
  상승형(시작 자금 증가 등)은 소량만 혼합.
- 난이도 확장은 어센션(리그 체급 상승) 방식을 우선 도입.
- 해임 시 이번 회차 성과 기반으로 메타 재화 정산.

## 11. 슬라이스(첫 수직 슬라이스) 범위 확정

**포함**
- 리그 2단계: 5부, 4부 (승격 보상·승격 전용 위기 검증에 필요)
- 구단 4종(성격 태그 강점/약점 쌍), 구단 선택 화면
- 선수 60~80장(절차적 생성) + GOD 2명(수작업), 플레이스타일 8종,
  대륙 5종, 특수 성향 6종
- 감독 9종 세부 성향 + 등급 4단계, 상시 순환 시장
- 스태프 2종(수석 코치, 수석 스카우터), 상시 순환 시장
- 경제: 계약/재계약, 방출 3단계, 윈터 택스, 상점형 드래프트(리롤 유료)
- 이벤트: 일반 위기 2종 + 일반 기회 3종 + 승격 전용 위기 2종
- 결산: 순위표 연출 + 핵심 사건 요약 + 예상 승점 범위 공개
- 저장: 브라우저 로컬 저장

**제외 (다음 마일스톤)**
- 사치세, 용병 부대 방지, 3부 이상 리그, 대륙 챔피언스 컵
- 메타 progression 해금 시스템, 무한 모드, 어센션 난이도
- 로그인/클라우드 저장/비상 복구
- 아키타입 태그, 정식 튜토리얼
- 보류된 이벤트(임대, 항공 지연, 사우디 자본, 데드라인 타임딜, 에이전트
  이중 계약, 강제 바이아웃, 사무국 행정 실수)
