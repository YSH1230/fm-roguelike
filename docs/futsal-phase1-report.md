# 풋살 1단계 보고서 (1~9장)

측정: `node tests/futsalVerify.mjs` (동급 1,000경기, 능력치 200경기, 평균 +2/+4 400경기). 자동 테스트 54개 통과(`node --test tests/futsal.test.mjs`).

## 정정
- 앞서 보고한 "패스 성공 약 78%"는 **틀린 수치**였다. 패스한 선수가 자기 공을 다시 줍는 버그(짧은 패스에서 passer가 곧바로 수신자로 처리됨)가 성공으로 잡혔다. 수정 후 실제 값은 아래와 같다. 이 버그 때문에 AI가 공을 쥐고 안 놓는 정체도 있었다.

## 목표 지표 (동급 팀, 경기당 팀 기준)
| 지표 | 목표 | 측정 |
| --- | --- | --- |
| 패스 개수 | 60~90 (1단계 임시 45~70) | 61.7 ✓ |
| 패스 성공 | 90% 이상 | **53.7% ✗** |
| 태클 시도 | 8~12 | 10.8 ✓ |
| 태클 성공 | 40~50% | 54.9% (약간 높음) |
| 슛 | 8~12 | 12.1 ✓(상단) |
| 슛당 득점 | 약 12% | 12.0% ✓ |
| 합계 골 | 2.1~2.9 | 2.9 ✓(상단) |
| 자동 수비만 막힘 | 10번 중 2~3 | **5.5 ✗** (공격 도달 후 소유권 상실 기준의 근사 측정) |

## 패스 성공이 낮은 원인 (수치)
- 패스의 96%가 상대 수비수 1.6m 안에서 나온다(1차 수비수가 1.3m로 붙어 있어서). 5~10m 패스 성공 44%, 10~15m 35%, 5m 미만 84%.
- 가로채기 반경 0.85m가 가장 크다: 0.6m면 성공 72%, 0.5m면 78%. 패스 오차 규칙은 영향이 거의 없다(오차 0으로 해도 같음).
- 수비 패스 길 차단 비중(`defense.laneShare`)을 0.3으로 줄이면 57%(+7%p).
- 보정 후보(문서 수치라 아직 안 바꿈): ① 가로채기 반경 0.6m, ② AI가 압박 중 패스를 덜 고르게, ③ `defense.laneShare` 완화. ①이 가장 크고 ②③은 보조.

## 능력치 독주 (한 능력치만 바꾼 팀 vs 전원 10, 승률)
| 능력 | 0 | 20 |
| --- | --- | --- |
| 속도 | 2.8% | **94.5%** |
| 체력 | 45.0% | 60.0% |
| 힘 | 42.8% | 61.3% |
| 패스 | 40.3% | 61.8% |
| 슛 | 32.0% | 69.0% |
| 기술 | 46.5% | **50.5%** (효과 거의 없음) |

- 평균 +2 팀 승률 69.8%(목표 약 60%), +4 팀 90.8%(목표 약 72%): 속도가 너무 크게 작용한다.
- 보정 후보: 달리기 속도 범위 6~9 → 6.75~8.25m/s로 좁히면 속도 20 승률 81%, +2 64.3%, +4 80.0%. 기술은 개인기 효과가 약해 별도 검토.

## 입력과 태클
- 입력 모사 15,000회 인식 오류 3.8%(목표 5% 이하) ✓. 오류의 대부분은 쓸기 판정(35px/0.5px/ms 경계).
- 태클 신호 보너스(동급): 스탠딩 34.5% → 54.8%, 슬라이딩 24.3% → 38.4% ✓.

## 목표를 맞추려고 둔 임시값(문서에 없음, 전부 TUNE)
`ai.*`(think, pressedThink, passLane, passMate, pass, passPressed, shotP, shotThink, shotLane, slack, nearOpp, nearCos), `defense.attemptPerSec`(0.05/0.07/0.12), `defense.randomAttempt` 0.02, `defense.laneError` 3.5, `shot.rangeBase` 12, `pass.freeFlight` 1.0(발을 떠난 뒤 1m는 가로채기 불가), `ring.kitLumDiff` 0.15, `difficulty.chanceMul` 1.2(지시에 따라 올림. 찬스 등급 표 테스트는 배수 1 기준으로 따로 검사).

## 문서와 코드 사이에서 정한 것
- `ringTau`, `ringColor`(열린 링)와 관련 TUNE을 삭제했다(문서: 열림 링 삭제).
- 슛/태클 통계: `stats.tackles`는 접촉 경합 승리를 포함하므로, 검증은 `tackleOk + tackleFails`(능동 태클)로 센다.

## 아직 직접 해 보기가 남은 것
9장 마지막의 휴대폰 체크리스트와 질문 3개는 사람이 해 봐야 한다. 입력 로그는 자동 저장된다(`?dev=1` 패널에서 내려받기).
