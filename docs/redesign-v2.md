# FM-Roguelike v2 개편 확정 문서

작성: 2026-10-10 · 상태: 확정(구현 착수) · 배포: 전부 끝난 뒤 **한 번에**

## 0. 목표
처음 여는 라이트 유저가 5분 안에 재미를 느끼고, 갈수록 깊어지는 **이적시장 중심의 축구 로그라이크**.
친구 피드백 두 줄("뭘 해야 할지 모르겠다", "설명이 부실한데 너무 많아서 눈에 안 들어온다")의 해결이 최우선.
FM에서 좋아하는 것은 이적시장(사고팔기), 경기는 지루했다 → 경기를 키우기보다 **이적시장을 주인공으로**.

## 1. 하지 않는 것
구단 이동, 미스터리 카드, 더비, 득점 기록과 가짜 스코어, 라이트 모드, 추천 영입/자동 진행, 용어 변경(OVR·적응도·이사진 그대로),
효과음(나중에), 공유와 오늘의 도전(배포 단계에서 다시 고민), 첫 시즌 해임 보호, 대진 배정(라운드 상대 팀명).

## 2. 규칙 변경
| 영역 | 확정 |
|---|---|
| 구단 | 승격 때 구단 이동 폐지. 승격 화면은 스타디움 성장과 축하. 승격 직후 "핵심 선수 이적 요구" 이벤트는 그대로 발생 |
| 계약 | **폐지**(재계약, 만료, 계약 박스, 1년/만료 배지 삭제) |
| 정원 | **22명 고정**(구현 중 26/24에서 줄이고 단일 값으로 통일). 정원이 차면 영입 때 내보낼 선수를 그 자리에서 고름(판매 등록 또는 즉시 방출) |
| 정원 예외 | 긴급 유스 콜업, 이벤트 무료 영입, 태업 복귀는 정원을 **일시 초과** 가능. 다음 시장 마감 전까지 정리, 안 하면 가장 낮은 OVR 자동 방출. 시즌 1→2 전환 때 초과분 정리 단계 |
| 거래 | 한 주 **첫 한 건은 적응도 감소 면제.** **교체 영입(영입+내보내기)은 1건**으로 셈. 여름에 산 선수는 **겨울부터** 판매 가능 |
| 판매(2시즌~) | 오퍼 도착(선수 가치에 비례한 1~3건, 금액은 기존 랜덤 범위: 여름 50~100%, 겨울 70~110%), 기다리면 새 오퍼로 교체, 각 시장 **마지막 주까지 안 팔리면 태업**: 선수단 복귀 + OVR −3(그 시즌 끝까지). 방출 버튼(원가 40%)은 유지. 1시즌은 기존 판매 등록(다음 주 랜덤 정산) |
| 태그 | **대륙 태그 폐지.** 플레이스타일 11종 유지. 발동 연출, "▲7" 분해(탭), 태그 목표 미리보기(태그 탭) — 새 상시 요소 없음 |
| 특수 성향 | 칸(주장/에이스/조커) 폐지, **6종 자동 적용 개성 배지**(폴리글롯 폐지). 같은 성향은 중복 적용 안 함. 스타 기질 가격 ×2→×1.5, 이야기성 대가(성골 유스 이적 요구, 지역 영웅 방출 시 적응도 −8)는 유지. 재계약 관련 대가는 삭제 |
| 이적 요구 | "러브콜" 등 이벤트로 가끔 선수가 떠나겠다고 함(붙잡기/보내기) |
| 나이 | 포지션별 노화(GK +3년·CB/DMF +1년 늦게, W/WB/ST −1년 빠르게), 시즌 시작 **도약 10%(+2 추가) / 정체 10%(성장 0 이하)**, **21세 이하 가격 +15% / 33세 이상 −15%**(GOD 제외), 카드에 추세 화살표(↗ → ↘) |
| 감독 불화 | 규칙 내용은 그대로, **감독 탭이 열리는 3시즌부터 발동.** 그 전에는 보너스도 벌칙도 사임도 없음 |
| 은퇴 앞둔 레전드 | "재계약 불가"를 "시즌 후 은퇴"로 변경 |
| 저니맨 | 영입 시즌에만 본인 +8 |

## 3. 시작 흐름과 튜토리얼
- 오프닝 뒤 5단계 설명 화면 삭제. 구단 카드는 2줄 + "처음이라면 추천" 구단 1개.
- 시즌 목표 화면: 한 줄과 막대, 나머지는 "자세히 보기". **"이 점수 밑이면 해임"을 반드시 한 줄에 포함.**
- 첫 런은 이사진 요구 선택 생략(2시즌부터 등장).
- 이름 입력: **구단주(단장) 이름**과 구단 이름(미리 채워짐, 건너뛰기 가능), 유니폼 색. 감독 카드는 그대로. 이름은 헤더, 은퇴 의식, 런 종료 문구 등 서사 자리에만 사용.
- **튜토리얼**(모두에게 한 번, 건너뛰기 가능, 화면을 어둡게 하고 눌러야 할 곳만 밝힘, 행동해야 다음 단계): ① 목표 ② 영입(실제로 한 명) → **영입 직후 기본기 태그 소개** ③ 전술 ④ 다음 주로 ⑤ 시뮬레이션과 전반기 결산.
- 첫 런의 영입 후보에는 **영입 가능하고 현재보다 강한 카드가 반드시 1장**.
- 적응도는 **첫 시즌부터 설명까지 포함해 표시.**

## 4. 해금(계정 기준, 한 번 열리면 계속 열림)
| 시점 | 열리는 것 |
|---|---|
| 첫 영입 직후 | 기본기 태그(패스·개인기·피지컬) |
| 첫 시즌 | MVP, 라운드 결과, 운명의 라운드, 적응도 |
| 2시즌 | 보통 태그, 이사진 요구, 판매 오퍼, 반기 전술 방향 |
| 3시즌 | 어려움 태그, 감독·스태프, 감독 불화 규칙, 특수 성향 배지 |

해금 안내는 튜토리얼과 같은 스포트라이트 방식(한 줄).

## 5. 재미 요소
- **라운드 결과 한 줄**: 승/무/패 + 순위 변화(상대 팀명 없음 — 리그에 대진 데이터가 없음). 가짜 스코어 없음.
- **운명의 라운드**(시즌 막판 승격/잔류 경쟁 연출), **이번 주 MVP**(승리 라운드마다 선발 중 한 명, OVR 가중).
- **높은 등급 연출**(모든 후보, 등급별 강도), **스타디움 성장**(5단계, 승격 화면/시즌 결산/런 종료/시작 화면에서만).
- **반기 전술 방향**: 반기 시작 전 공격/균형/수비.
- 선수 사연 한 줄, 내 선수의 기록(MVP 횟수, 뛴 시즌)과 **클럽 레전드**, 은퇴 의식, 성격 이벤트, 개성 도감, 유니폼 색.

## 6. 화면 원칙
새로 항상 보이는 요소를 만들지 않는다(하나를 넣으면 하나를 뺀다). 예외는 정원 표시(선수단 탭의 기존 숫자 "20"→"20/24")와
나이 추세 화살표(나이 숫자 옆 글자 하나).

## 7. 통계(개인정보 없음)
- 시즌/런 종료 기록에 더해 튜토리얼 단계 도달·건너뛰기, 첫 영입까지 걸린 시간, 첫 시즌 완료 여부.
- **사용자가 입력한 이름(구단주, 구단)은 절대 보내지 않고** 기본 구단 id만 보낸다.
- 규칙 버전(`v`)을 구분해서 이전 데이터와 섞이지 않게 한다.

## 8. 진행과 배포
- 별도 브랜치(`v2`)에서 작업. 끝나면 `main`에 합쳐 한 번에 배포. 그 전까지 친구들은 현재 버전을 씀.
- 배포 때 **진행 중인 판은 초기화**(기록, 업적, 최고 점수는 유지). 친구들에게 사전 공지.
- 순서: ① 규칙 개편 → ② 밸런스 재조정(시뮬레이션, 제가 조정하고 결과 보고) → ③ 시작 흐름·튜토리얼·해금 → ④ 재미 요소 → ⑤ 통계·점검.
- **필수**(없으면 배포 안 함): ①②③과 라운드 결과·MVP·운명의 라운드, 통계.
  **후순위**(늦어지면 다음 배포): 성격 이벤트, 개성 도감, 은퇴 의식, 유니폼 색, 사연 한 줄, 스타디움 성장 세부.
- 수치(정원, 태업 −3, 가격 ±15%, 도약/정체 10%, 노화 보정 등)는 시작값이며 시뮬레이션과 플레이로 조정.
- 명성 점수 등급·칭호 컷과 업적 기준은 규칙 개편 후 다시 측정.

## 9. 구현 기록 (2026-10-10, `v2` 브랜치)
- ① 규칙: 대륙·폴리글롯·역할 칸 폐지, 계약 폐지, 정원 26→24와 내보낼 선수 고르기, 한 주 첫 거래 적응도 면제와 교체 영입 1건, 여름 영입은 겨울부터 판매, 판매 오퍼와 태업(2시즌~), 포지션별 노화와 도약·정체, 나이별 가격, 추세 화살표, 승격 때 구단 이동 폐지, 감독 불화는 3시즌부터.
  - 정원 초과 정리는 "시즌 1→2 전환 때 별도 단계" 대신 **각 시장 마감 때 선발·벤치가 아닌 낮은 OVR부터 자동 방출**로 단순화했다(선수단 탭 숫자가 빨갛게 변해 알려 준다).
  - 판매 오퍼는 등록하는 즉시 첫 오퍼가 오고, 매주 새 오퍼로 바뀐다. 시장 마감까지 안 팔리면 태업(OVR −3, 그 시즌 끝까지).
- ② 밸런스: 사람처럼 플레이하는 봇(`tools/sim-human.mjs`) 300판으로 v1 승점 분포에 맞췄다.
  - 대륙 시너지(평균 +3.2/선수)와 재계약비가 사라져 5부는 어려워지고 상위 리그는 돈이 남았다 → 시즌 자금 배율 `FUNDS_SCALE`(첫 시즌 ×1.25, 5부 .85, 4부 .85, 3부 .75, 2부 .7, 1부 .45)와 리그 평균 OVR(5부 44~52, 4부 52~60, 3부 57~64, 1부 71~79)로 보정.
  - 첫 시즌 평균 승점 v1 55.9 → v2 55.8, 강등 12.5% → 약 10%. 4부 71.0 → 70.9, 3부 72.0 → 71.9, 2부 75.7 → 74.6.
  - 명성 등급 컷 C200 / B550 / A800 / S1100 / SS1700, 업적 기준도 같이 맞췄다.
- ③ 시작·튜토리얼·해금: 5단계 설명 삭제, 구단 카드 2줄+추천, 구단주/구단 이름·유니폼 색, 목표 한 줄+자세히 보기, 첫 시즌은 이사진 요구 생략, 스포트라이트 튜토리얼 6단계(건너뛰기), 계정 단위 해금(보통 태그·이사진 요구·반기 전술 방향 2시즌, 어려움 태그·감독·스태프·특수 성향 3시즌).
- ④ 재미: 라운드 결과 한 줄(승/무/패·순위 변화), 승리 라운드 MVP, 운명의 라운드, 반기 전술 방향(공격/균형/수비), 높은 등급 카드 연출, 태그 발동 알림, 스타디움 5단계(승격·런 종료 화면).
- ⑤ 통계·배포: 통계 버전 `v2-2026-10-10`, 구단은 기본 id만 전송, 튜토리얼 단계·건너뜀·첫 영입까지 걸린 시간 추가. 이전 규칙 세이브는 이어하기 불가(기록·업적·최고 점수는 유지).
- **후순위 처리(2026-10-10)**: 선수 사연 한 줄은 삭제(재미 없다고 판단). 클럽 레전드(6시즌+MVP 15회, 팔면 적응도 -8)·MVP 기록·은퇴 인사, 성격 이벤트 2종, 특수 성향 업적(도감 대체), 단장 이름은 브리핑 제목, 새 기능 첫 마주침 안내는 구현함. 은퇴 의식은 팝업 대신 브리핑 한 단락으로 처리.

## 10. 태그 개편 (2026-10-10)
- 태그 11종·3등급 → **6종 한 층**(패스 플레이·돌파·몸싸움·전방 압박·역습·후방 빌드업). 규칙은 하나: 같은 태그를 가진 선발이 3/4/5명이면 보유자 전원이 +1/+2/+4(포지션 제한 없음).
- **성장 중 → 완성**: 전성기 전 선수는 태그 효과 절반(인원에는 그대로 셈). 전성기에 닿으면 완성.
- **팀 컬러**: 가장 많이 모인 태그가 팀 스타일 이름이 된다(압박 축구 등). 전술 탭 "팀 스타일" 패널, 시즌 결산, 런 종료 화면(가장 오래 쓴 스타일)에 나온다.
- 화면: 영입 탭 "내 태그" 패널과 태그 필터 삭제, 카드 칩은 아이콘만(영입하면 발동되는 태그는 ▲), 전술 탭 한 곳에서 6종 진행을 본다.
- 해금: 처음 3종(패스·돌파·몸싸움)은 1시즌, 나머지 3종은 2시즌. 어려움 태그 해금(3시즌)은 없어짐.
- 진행 중인 판은 이어하기 불가(규칙 버전 3).
