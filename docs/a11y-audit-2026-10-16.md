# 접근성·터치·대비 점검 (2026-10-16, 폰 390 실측 + 스킬 기준)

측정 방법: 실제 앱에서 화면별로 보이는 버튼·글자를 자동 측정(터치 44px, 글자 12px, 대비 4.5:1/3:1, 칩 줄바꿈, 라벨, 모달 포커스).

## 모달·컷신
- 모달(.eventmodal): role="dialog"/aria-modal/aria-label 없음, 열릴 때 포커스가 모달로 안 옮겨짐(BODY 유지), Tab이 모달 밖으로 빠짐, Esc로 안 닫힘.
- 컷신(.dlg): 클릭 전용 div, 키보드(Enter/Space)로 다음 줄 안 넘어감, 건너뛰기 버튼 높이 18px.
- 포커스 링: outline 제거 규칙 0건, :focus-visible 규칙 6건 → 대체로 양호. prefers-reduced-motion 처리 있음.

## 제안(우선순위)
1. [CSS] 터치 영역 44px: 헤더 알약·갭칩·태그칩·포메이션 알약·행동 버튼·셀렉트에 min-height 44(눈에 보이는 크기는 유지하고 패딩/::after로 확장 가능).
2. [CSS] 전술 필드 슬롯 글자 9~10px → 11~12px(필드 카드가 커지는 만큼 이름 줄임).
3. [JS] 모달: role=dialog + aria-modal, 열 때 첫 버튼 포커스, Tab 순환, Esc 닫기(닫을 수 있는 모달만), 닫을 때 이전 포커스 복귀.
4. [JS] 컷신: Enter/Space로 다음, 건너뛰기 버튼 44px, aria-live로 대사 읽기.
5. [CSS] 전술 게이트 표시 대비 4.1 → 4.5 이상.
