# FM-Lite 디자인 규칙 (리서치 랩)

레퍼런스 세 장과 `DESIGN-theverge.md`의 구조 원칙(어두운 캔버스, 평평한 깊이, 1px 선, 그림자와 장식 그라디언트 금지)에서 뽑았다. 샘플은 `next/dev/lab-sample.html`.

## 분위기

**스포츠 리서치 랩의 선수 리포트.** 짙은 회색 바탕 위에 작은 대문자 라벨, 점선 구분선, 끝이 뾰족한 막대가 놓이고, 숫자는 좁고 굵은 글씨로 크게 외친다. 내 수치는 주황, 평균은 회색, 최고는 금색. 업적은 방패 배지로 모은다.

- 레퍼런스 1: 굵고 기하학적인 **아이콘**(틈은 따르지 않는다)과 굵은 대문자 라벨.
- 레퍼런스 2: 어두운 **데이터 리포트** 화면(점선, 밑줄 소제목, 비교 막대).
- 레퍼런스 3: **좁고 굵은 대문자 글씨**, 큰 숫자 하나에 작은 통계 셋, 밑줄 탭, 3열 배지 격자.

## 1. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#222222` | 모든 화면(**라이트 모드 없음**) |
| 패널 | `#2c2c2c` | 한 단계 위 면(입력줄, 선택된 행) |
| 선 | `#4a4a4a` | 점선·구분선·테두리 |
| 하양 | `#ffffff` | 글, 소제목 밑줄, 윤곽 버튼 |
| 보조 글 | `#9a9a9a` | 부속 정보, 라벨 |
| **YOU 주황** | `#ff4a1c` | 내 수치, 내 선수, 주 행동(버튼) |
| **BEST 금색** | `#b9a35a` | 최고 기록, 리포트 라벨 |
| **AVERAGE 회색** | `#8d8d8d` | 평균, 비교 기준 |
| **볼트 노랑** | `#d4f500` | 달성 배지 테두리(기본 방패), 중요한 달성 |
| 아이콘 연보라 | `#d9ceff` / 라벨 `#a97cff` | 아이콘과 아이콘 라벨 |
| 메탈 금·은·동 | 아래 4번 | 업적 등급 |

- 주황은 "나"에게만 쓴다. 리그 평균, 상대, 다른 팀에는 쓰지 않는다.
- 위험(부상, 패배, 강등)은 주황의 더 진한 톤이 아니라 **하양 글자 + 아이콘**으로 알리고, 색 면이 필요하면 `#ff4a1c`를 면으로 쓴다(막대와 같은 뜻: "내 것이 안 좋다").
- 그림자는 쓰지 않는다. 장식 그라디언트도 없다. 그라디언트는 **메탈릭 배지**에만 쓴다.

## 2. 글자

| 역할 | 글꼴 | 크기 / 굵기 | 자간 |
|---|---|---|---|
| 화면 큰 제목(선수 이름 등) | Barlow Condensed | 56 / 800, 대문자 | 0.01em |
| 큰 숫자(시즌 골, 순위) | Barlow Condensed | 56~120 / 800 | 0 |
| 소제목 | Barlow Condensed | 17 / 700, 대문자 | 0.06em |
| 컬럼 제목(밑줄) | Barlow Condensed | 14 / 700, 대문자 | 0.1em |
| 라벨 | Barlow Condensed | 11 / 600, 대문자, 보조 글색 | 0.14em |
| 비교 수치 | Barlow Condensed | 30 / 700(YOU), 26(평균·최고) | 0 |
| 한글 글 | Pretendard | 13~15 / 400~700 | 0 |

- 큰 글씨와 라벨은 **영문 대문자**로 쓰고 한글 뜻을 옆에 작게 붙인다(예: `SHOOTING 슈팅`). 한글에는 좁고 굵은 글씨체가 없어서 이 방식으로 맞춘다.
- 영문 대문자 라벨에는 항상 자간을 준다(0.06~0.16em).
- 선수 이름은 성(Last)을 크게 대문자로, 이름과 나이는 보조 글색으로 작게.

## 3. 모양

- **각진 모서리가 기본이다.** 패널, 막대, 버튼은 반지름 0~2px. 둥근 알약은 쓰지 않는다.
- 배지는 방패 모양(`clip-path`: 위 직사각형, 아래 V자).
- 구분은 선: 섹션 머리는 `1px dotted #4a4a4a`, 컬럼 제목 밑줄은 `2px solid #fff`, 탭 활성은 `3px` 흰 밑줄.
- 구단 크레스트와 도트 초상화는 그대로 쓴다(1px 선으로 두른 사각 틀).

## 4. 부품

**리포트 머리**: 왼쪽에 금색 `FM-LITE` + 보조 라벨(`PLAYER REPORT`), 오른쪽에 `SEASON 1 / ROUND 14`. 아래에 점선.

**비교 막대(YOU / AVERAGE / BEST)**
- 18px 높이, 칸은 `#1b1b1b`, **왼쪽에서 시작**해 오른쪽 끝이 화살촉 모양(14px 뾰족).
- 위에 라벨(`YOU` 주황, `AVERAGE` 회색, `BEST` 금색, 11px 대문자)과 수치(`62 / 100`).
- 아래에 눈금 `0 · 50 · 100`(10px, `#666`).
- 능력치와 시설·코치 같은 모든 수치 막대에 이 모양을 쓴다(색은 뜻에 맞게).

**큰 숫자 + 통계 셋**: 가운데 정렬된 큰 숫자(120px) 아래 설명 한 줄, 그 아래 3열 작은 통계(28px 숫자 + 13px 한글 라벨).

**버튼**: 주(주황 칠, 하양 글자, 17 / 800 대문자, 자간 0.12em, 높이 48), 보조(1px 하양 테두리). 한 화면에 주 버튼 하나. 눌림은 불투명도 0.85.

**탭**: 대문자 15 / 700, 활성은 하양 + 3px 밑줄, 나머지는 보조 글색. 하단 탭은 같은 규칙에 아이콘이 위에 붙는다.

**업적 배지**: 방패, 안쪽은 어두운 면, 테두리와 아이콘이 금속 광택. 아래에 이름(대문자), 설명(한글), 등급과 시각 한 줄(`GOLD · YEAR 2`).

## 5. 업적 등급(메탈릭)

| 등급 | 기준 | 테두리·아이콘 |
|---|---|---|
| **GOLD** | 큰 업적: 리그 우승, 챔피언스리그, 발롱도르 | `#fff3b0 → #f0c94c → #b8860b → #f8e58a → #a67c12` |
| **SILVER** | 중간 업적: 승격, 득점왕, 시즌 MVP | `#ffffff → #d5dade → #8d949c → #eef1f3 → #7b828a` |
| **BRONZE** | 작은 업적: 연승, 무패 구간, 첫 승격 | `#ffd9b0 → #dc8f50 → #8f4f21 → #f0b685 → #6e3a14` |
| **LOCKED** | 아직 못 얻음 | 회색 `#4a4a4a → #333`, 아이콘 없음 또는 어둡게 |

- 메탈 그라디언트는 135도 방향, 이 배지 테두리와 아이콘 선에만 쓴다.

## 6. 아이콘

- 24 격자, **선 굵기 3**, 끝 모양 `butt`(선이 모이는 곳에서 튀어나오지 않게), 꺾임 `miter`. 직선, 직각, 45도, 원호로만 만든다.
- **대칭을 지킨다**: 좌우 대칭 사물(유니폼, 방패, 하트, 트로피, 지구본, 고깔)은 중심선 x=12에 정확히 맞춘다. 화살표 두 개는 12,12를 중심으로 180도 대칭으로 둔다.
- **선이 만나는 곳은 한 점에서 끝낸다**: 화살표의 줄기는 머리의 꼭짓점에서 끝나고 끝이 겹쳐 튀어나오지 않는다. 가능하면 한 경로로 이어서 그린다.
- **틈 없이 이어진 선**으로 그린다. 윤곽을 일부러 끊거나 비우지 않는다(끊긴 틈이 눈에 거슬린다는 사용자 판단).
- 아이콘 아래 라벨은 영문 대문자 14 / 700, 자간 0.06em, 연보라 `#a97cff`.
- 이모지와 기호 글자를 아이콘으로 쓰지 않는다. 모든 아이콘은 `next/ui/icons.mjs`에 같은 규칙으로 모은다.

## 7. 게임에 옮기기

| 이 게임의 것 | 리서치 랩 부품 |
|---|---|
| 선수 상세 | 리포트 머리 + 성(Last) 대문자 큰 제목 + `YOU / AVERAGE / BEST` 능력치 비교(같은 포지션 리그 평균·최고) + 큰 숫자(시즌 골)와 통계 셋 |
| 로스터(축구장 보드) | 그대로 두되 선수 타일은 각진 사각, 이름 라벨은 대문자 모양 |
| 순위표 | 점선 구분 행, 내 행은 주황 1px 테두리 |
| 경기 결과 | 큰 숫자(승패)와 작은 통계 셋(승·무·패), 경기 목록은 점선 행 |
| 시즌 종료, 은퇴·경질 | 큰 숫자(순위·점수) + 통계 셋 + 업적 배지 격자 |
| 기록실 | `HISTORY / ACHIEVEMENTS / SEASONS` 탭 + 3열 배지 격자 |
| 프런트(시설·코치·캡) | 수치 막대(화살촉 막대)와 컬럼 제목 밑줄 |
| 오프시즌 | 컬럼 제목이 `RESIGN / MARKET / DRAFT / ROOKIES`인 밑줄 탭 |

## 8. 움직임

- 눌림, 화면 전환 페이드(0.14초), 결과 줄과 무대 입장만. 읽는 숫자는 움직이지 않는다.
- 막대는 처음 보이는 화면에서만 왼쪽에서 채워진다(0.35초, 한 번).
- 모션 줄이기에서는 이동을 빼고 투명도만.

## 9. 지킬 것

**Do**
- 바탕은 늘 어둡다. 구분은 선으로, 높이는 대비로.
- 큰 글씨·라벨은 영문 대문자 + 한글 작은 뜻.
- 수치는 YOU / AVERAGE / BEST 비교로 보여 준다(기준이 있을 때).
- 터치 영역 44px 이상(작은 라벨 탭은 패딩으로 늘린다).

**Don't**
- 둥근 알약 버튼, 그림자, 장식 그라디언트(메탈 배지 제외), 각진 것 사이의 둥근 카드.
- 주황을 "내 것" 이외에 쓰기.
- 자간 없는 대문자 라벨, 이모지·기호 글자 아이콘, 끊긴 틈이 있는 아이콘.

## 드래프트 화면 기준 (메인 컨셉)

드래프트 화면이 이 게임 화면의 기준 톤이다. 다른 화면도 이 규칙을 따른다.

- 화면 안의 글자는 영어. 영어 라벨 뒤에 한글을 덧붙이지 않는다. 라벨은 12px 이상, 대문자 + 넓은 자간.
- 왼쪽 선은 하나. 제목·요약(순번, 직전 지명 등)·섹션 제목은 상자 없이 같은 왼쪽 선에서 시작하고, 선수 줄만 상자(panel)로 둔다.
- 선수 줄: 첫 줄은 이름만(말줄임), 둘째 줄은 `[포지션] AGE n 별점`을 고정 칸에 맞춘다. 오른쪽에는 펼침 화살표(박스 없음)와 주 버튼.
- 세부 정보는 눌러서 펼친다. 능력치는 3글자 약자(PAC SHO PAS DRI DEF PHY / REF HAN POS DIV)와 흰 일자 막대, 숫자 없이. 천장(잠재)은 하늘색으로 이어 붙인다.
- 별점: 현재 금색(#f2c230), 잠재 하늘색(#3ec9ff), 0.5 단위. 팀 색과 무관하게 고정. 범례(NOW / POTENTIAL)는 섹션 제목 줄 오른쪽.
- 팀 색은 주 버튼, 내 차례 강조, 순번 숫자, 선택 테두리에 쓴다.
- 모션: 버튼 눌림 scale(.97) 0.14초, 결과 보드 줄 순차 입장(20ms 간격). 펼침·목록 페이드는 쓰지 않는다.
- 선수 카드: 왼쪽 위 포지션, 오른쪽 위 사기 표정, 가운데 초상화, 아래 이름·현재 별점·체력.
