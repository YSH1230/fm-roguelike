# FM-Lite 게임 규칙 (확정본)

논의해서 정한 것만 적는다. 숫자 밸런스는 화면이 정해진 뒤에 맞춘다.

## 1. 시즌 진행 순서 (확정)

- 시작 드래프트(첫해만) -> 관리 화면 -> 구간 1·2·3 -> 시즌 종료 -> 오프시즌(재계약, FA 시장, 신인 드래프트, 신인 배치) -> 다음 해.
- 구간은 3개(14·14·10라운드). 구간이 끝날 때마다 결과·기자회견·인터뷰·트레이드 제안.
- 구간 사이에 하는 일은 제한하지 않는다(코치 고용, 시설 투자, 트레이드, FA 영입, 휴식 지정, 레벨업 포인트).
- 오프시즌 단계 4개를 유지한다.
- 시즌 건너뛰기(빠른 진행)는 만들지 않는다. 시즌 진행이 이미 빠르다.

## 2. 선수 성장 (확정)

- 능력치마다 천장이 있고, 레벨업마다 포인트 1개를 능력치 하나에 +1.
- 모든 능력치가 천장이면 성장 끝(레벨만 오른다). 노화는 현재 값만 내리고 천장은 그대로.
- 선수 이름은 내 팀 선수만 바꿀 수 있다.

## 3. 스토리 (확정)

- 창단 이야기. 내가 구단을 새로 세워 3부 리그에 가입한다. 시작 드래프트는 리그가 처음 여는 신인 드래프트이고, 신생 팀이라 내 구단은 작년 순위가 하위권으로 매겨진다.
- 플레이어는 구단의 초대 감독이다. 구단주(이름 있는 별도 인물)가 감독직을 제안하고, 구단 이름과 색은 구단주가 감독에게 맡긴다.
- 감독 이름은 플레이어가 직접 짓는다. 선임 장면, 기자회견, 마지막 요약에 계속 쓰인다.
- 구단주는 경질의 주체(3부 19위 이하, 강등 시 해임)이고, 코인은 구단주가 대는 예산이다. 감독이 은퇴하거나 해임되면 한 판이 끝나고 경력 요약이 감독의 커리어 기록이 된다.
- 구단주 이름: OH SEUNGMIN (바꿀 수 있다).
- 시작 연출 4장면(건너뛰기 가능): 1 구단주의 제안 -> 2 감독 선임(이름·구단 이름·색 입력) -> 3 사무국 드래프트 안내(신생 팀이라 순번이 뒤쪽) -> 4 첫 선수단 소개 -> 드래프트.
- 시즌 중 이야기(승격, 우승 장면)는 시작 연출 뒤에 추가한다.

## 4. 영입 경로 (확정)

- 드래프트, FA, 트레이드, 재계약을 모두 유지한다. 스타는 6명 한도(새로 들이면 한 명을 내보낸다. 내보낸 선수는 FA로 나온다).
- **FA는 늘 열려 있다.** 시즌 중에도 FA 목록을 보고 영입한다. 목록은 시즌 동안 고정이고(AI 구단이 중간에 데려가지 않는다), 매 시즌 새로 초기화된다. 오프시즌 `MARKET` 단계는 새 FA가 도착하는 순간으로 남긴다.
- **트레이드는 선수끼리, 지명권끼리, 선수와 지명권을 서로 맞바꾼다.**
- **지명권은 해당 구단의 작년(방금 끝난 시즌) 순위로 순번이 정해진다.** 시즌이 끝나면 최종 순위의 꼴찌가 1번이다. 지명권을 거래해도 순번은 지명권이 가리키는 구단의 순위를 따른다.
- **오프시즌 드래프트는 2라운드.** 순번은 1·2라운드가 같다(꼴찌가 먼저). 후보는 40명, 뒤쪽 후보는 잠재력이 낮다.
- 1라운드 신인은 지금처럼 받는다. **2라운드 신인은 계약하거나 돈(코인)으로 받는 것 중 선택**한다. 돈으로 받으면 선수는 만들어지지 않는다.
- **시작 드래프트는 1라운드**(선수 5명 + 1명 = 6명).
